# HANSEONG SEO Image Library

Đặt ảnh thực tế dùng cho bài SEO vào thư mục này.

Cơ chế đăng bài sẽ ưu tiên ảnh trong thư mục này trước, dựa theo tên file khớp với keyword hoặc tiêu đề bài viết trong `data/blog_queue.json`.

Quy tắc đặt tên khuyến nghị:

- `mounjaro-2-5mg-real-order.jpg`
- `ozempic-wholesale-stock.webp`
- `juvederm-ultra-3-4-customer-delivery.jpg`
- `botox-allergan-50u-inventory.png`
- `skin-booster-rejuran-healer-clinic-order.jpg`

Lưu ý:

- Dùng định dạng `.jpg`, `.jpeg`, `.png`, `.webp`, hoặc `.jfif`.
- Tên file nên có tên sản phẩm, dung tích/phiên bản nếu có, và ngữ cảnh ảnh như `stock`, `order`, `delivery`, `clinic`, `inventory`.
- Trước khi đưa lên web, hãy che số điện thoại, địa chỉ cá nhân, mã vận đơn, thông tin ngân hàng hoặc dữ liệu riêng tư nếu ảnh có chứa.
- Nếu không có ảnh khớp tên sản phẩm, hệ thống sẽ fallback sang ảnh thực tế theo ngữ cảnh kho hàng/đơn hàng, rồi mới dùng ảnh sản phẩm mặc định.
